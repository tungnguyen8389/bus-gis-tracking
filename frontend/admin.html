Hệ Thống & Module Tách Biệt

Hệ thống hỗ trợ quản trị tách biệt độc lập từng thực thể dữ liệu:

  • Tọa độ & Lộ trình (GIS Spatial): Quản lý mảng tọa độ `LineString` tim đường phân theo từng tuyến và chiều di chuyển.
  • Trạm đón/trả khách: Quản lý tọa độ `Point` chuẩn WGS84 (SRID 4326), tên trạm và gán trạm theo từng tuyến/chiều cụ thể.
  • Đội xe & Lịch trình: Quản lý phương tiện, biển số, tài xế, trạng thái và giờ xuất bến.
  • Nhập/Xuất JSON: Cho phép import file `.json` hoặc dán trực tiếp chuỗi JSON để cập nhật tọa độ cho từng tuyến cụ thể.
  • Xác thực & Người dùng: Bảo mật bằng JSON Web Token (JWT) và mã hóa Bcrypt.
